## Start the server

Bring up `serve.sh {fePort}` for the duration of this task.

```js fixtures
({
  baseDir: ".",
  fePort: "5180"
})
```

```sh command
# Enter project dir
cd {baseDir}
mkdir -p .ololo/tmp

# Run command from session memory (LLM-extracted from AGENTS.md/README.md;
# arrives shell-quoted, so assign then invoke via word-splitting $R)
R={memory.run}
# Start web server in background (stays up for all sections of this task)
$R {fePort} >.ololo/tmp/esb_final.log 2>&1 &

# Wait for server boot
sleep 3

# Probe root; any HTTP response means listening
curl -s -o /dev/null -w "%{http_code}" "http://localhost:{fePort}/"

# Guarantee exit 0
true
```

```js validation
Number(result.trim()) >= 200 && Number(result.trim()) < 500
```

## Answer a warmup question

Every round starts with the warmup question.

```js fixtures
({
  baseDir: ".",
  fePort: "5180",
  id: Math.random().toString(36).slice(2, 10)
})
```

```sh command
# Open page and wait for settle
agent-browser open "http://localhost:{fePort}/" >/dev/null 2>&1
agent-browser wait --load networkidle >/dev/null 2>&1

# Snapshot to resolve input/button refs
agent-browser snapshot -i > .ololo/tmp/esb_snap_final_w.txt 2>/dev/null
inputRef=$(awk '/textbox/{sub(/.*ref=/,""); sub(/\].*/,""); print; exit}' .ololo/tmp/esb_snap_final_w.txt)
submitRef=$(awk '/button/{sub(/.*ref=/,""); sub(/\].*/,""); print; exit}' .ololo/tmp/esb_snap_final_w.txt)

# Type question, submit, wait for #answer
agent-browser fill "$inputRef" "{id}: what is your name" >/dev/null 2>&1
agent-browser click "$submitRef" >/dev/null 2>&1
agent-browser wait 1500 >/dev/null 2>&1

# Read and trim #answer
agent-browser get text "#answer" | sed 's/^[[:space:]]*//;s/[[:space:]]*$//'

# Guarantee exit 0
true
```

```js validation
result.trim().length > 0
```

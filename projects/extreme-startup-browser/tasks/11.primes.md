## Answer the primes question with the prime numbers from the list

Build a candidate list mixing small primes with obvious composites. Ask "which of the following numbers are primes: ...". #answer must list exactly the primes, in any order. Compared as sorted sets.

```js fixtures
({
  baseDir: ".",
  fePort: "5180",
  id: Math.random().toString(36).slice(2, 10),
  list: [2, 3, 5, 7, 11, 13, 17, 4, 6, 8, 9, 10, 15, 21, 25].sort(() => Math.random() - 0.5).join(", ")
})
```

## Start the server and answer the Fibonacci question

Bring up `serve.sh {port}`, wait for it to boot, then sample n in [4,23], build the ordinal (1st/2nd/3rd/Nth) and ask "what is the {ordinal} number in the Fibonacci sequence". Verify the response equals F(n) where F(0)=0, F(1)=1, F(2)=1, F(3)=2...

```js fixtures
({
  baseDir: ".",
  port: "8088",
  qid: Math.random().toString(16).slice(2,10),
  ...(() => {
    const n = Math.floor(Math.random() * 20) + 4;
    const s = ["th","st","nd","rd"], v = n % 100;
    const ordinal = n + (s[(v-20)%10] || s[v] || "th");
    return { n, ordinal };
  })()
})
```

```sh command
# Enter the project directory
cd {baseDir}
mkdir -p .ololo/tmp

# Run command from session memory (LLM-extracted from AGENTS.md/README.md;
# arrives shell-quoted, so assign then invoke via word-splitting $R)
R={memory.run}
# Kill any stale server on this port
pkill -f "serve.sh {port}" 2>/dev/null

# Wait for the port to free up
sleep 1

# Start the web server in the background
$R {port} >.ololo/tmp/es_fib.log 2>&1 &

# Wait for the server to boot
sleep 3

# Ask the Fibonacci question and trim the response
curl -s -G "http://localhost:{port}/" --data-urlencode "q={qid}: what is the {ordinal} number in the Fibonacci sequence" | sed 's/^[[:space:]]*//;s/[[:space:]]*$//'
```

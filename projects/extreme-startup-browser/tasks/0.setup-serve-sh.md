## Declare how to run the project

AGENTS.md (or README.md) must document how to run the project and contain a `run:` line declaring the command that starts your server, e.g. `run: sh serve.sh`. Every later probe starts the server by invoking exactly that command with the port appended. The declared command must reference `serve.sh` (the participant contract). AGENTS.md wins when both declare one.

```yaml probe
mode: deterministic
executor: participant
capture_memory: run
```
```js fixtures
({
  baseDir: "."
})
```

```sh command
# Enter project dir
cd {baseDir}
mkdir -p .ololo/tmp

# Extract the declared run command (AGENTS.md wins over README.md)
sed -n 's/^run: *//p' AGENTS.md README.md 2>/dev/null | head -1 | tr -d '\r'
```

```js validation
result.trim().length > 0 && result.includes("serve.sh")
```

The participant contract requires a `serve.sh` script at the project root that takes a port argument and starts a web server.

## Verify serve.sh starts a web server that responds on the given port

Run `serve.sh {fePort}` in the background, wait for startup, then curl the root endpoint. Any HTTP response (even 404) proves the server is listening.

```js fixtures
({
  baseDir: ".",
  fePort: "5180"
})
```

```sh command
# Enter project dir
cd {baseDir}
mkdir -p .ololo/tmp

# Run command from session memory (LLM-extracted from AGENTS.md/README.md;
# arrives shell-quoted, so assign then invoke via word-splitting $R)
R={memory.run}
# Start web server in background
$R {fePort} >.ololo/tmp/esb_setup.log 2>&1 &

# Wait for server boot
sleep 3

# Probe root; any HTTP response means listening
curl -s -o /dev/null -w "%{http_code}" "http://localhost:{fePort}/"

# Tear down the server
pkill -f "serve.sh {fePort}" 2>/dev/null

# Guarantee exit 0
true
```

```js validation
const code = Number(result.trim()); code >= 200 && code < 500
```

## Verify the page renders the question input, submit button, and answer element

Open the page in a headless browser; it must expose at least one text input, one button, and an element with id "answer".

```js fixtures
({
  baseDir: ".",
  fePort: "5180"
})
```

```sh command
# Enter project dir
cd {baseDir}
mkdir -p .ololo/tmp

# Run command from session memory (LLM-extracted from AGENTS.md/README.md;
# arrives shell-quoted, so assign then invoke via word-splitting $R)
R={memory.run}
# Start web server in background
$R {fePort} >.ololo/tmp/esb_setup_dom.log 2>&1 &

# Wait for server boot
sleep 3

# Open page and wait for settle
agent-browser open "http://localhost:{fePort}/" >/dev/null 2>&1
agent-browser wait --load networkidle >/dev/null 2>&1

# Snapshot interactive elements to count
agent-browser snapshot -i > .ololo/tmp/esb_snap_setup.txt 2>/dev/null
inputs=$(grep -c 'textbox' .ololo/tmp/esb_snap_setup.txt)
buttons=$(grep -c 'button' .ololo/tmp/esb_snap_setup.txt)

# Confirm #answer element exists. Presence is the element being found, not
# its text: the brief requires #answer EMPTY on a fresh page, and the old
# `$(get text; echo present)` capture turned that empty text into a
# leading newline that broke the validation regex — a fully compliant page
# failed this probe on every attempt (session US2KZ6: 0/17, -30).
answerEl=$(agent-browser get text "#answer" >/dev/null 2>&1 && echo present || echo missing)
echo "inputs=$inputs buttons=$buttons answer=$answerEl"

# Tear down browser and server
agent-browser close >/dev/null 2>&1
pkill -f "serve.sh {fePort}" 2>/dev/null

# Guarantee exit 0
true
```

```js validation
const m = result.match(/inputs=(\d+) buttons=(\d+) answer=(present|missing)/); m && Number(m[1]) >= 1 && Number(m[2]) >= 1 && m[3] === "present"
```

## Verify the page answers a one-shot question end-to-end

Fill the input with a trivial arithmetic question, click submit, then read `#answer` and assert it equals 0 with exit code 0.

```js fixtures
({
  baseDir: ".",
  fePort: "5180",
  id: Math.random().toString(36).slice(2, 10)
})
```

```sh command
# Enter project dir
cd {baseDir}
mkdir -p .ololo/tmp

# Run command from session memory (LLM-extracted from AGENTS.md/README.md;
# arrives shell-quoted, so assign then invoke via word-splitting $R)
R={memory.run}
# Start web server in background
$R {fePort} >.ololo/tmp/esb_setup_e2e.log 2>&1 &

# Wait for server boot
sleep 3

# Open page and wait for settle
agent-browser open "http://localhost:{fePort}/" >/dev/null 2>&1
agent-browser wait --load networkidle >/dev/null 2>&1

# Snapshot to resolve input/button refs
agent-browser snapshot -i > .ololo/tmp/esb_snap_e2e.txt 2>/dev/null
inputRef=$(awk '/textbox/{sub(/.*ref=/,""); sub(/\].*/,""); print; exit}' .ololo/tmp/esb_snap_e2e.txt)
submitRef=$(awk '/button/{sub(/.*ref=/,""); sub(/\].*/,""); print; exit}' .ololo/tmp/esb_snap_e2e.txt)

# Type question, submit, wait for #answer
agent-browser fill "$inputRef" "{id}: what is 0 plus 0" >/dev/null 2>&1
agent-browser click "$submitRef" >/dev/null 2>&1
agent-browser wait 1500 >/dev/null 2>&1

# Read and trim #answer
agent-browser get text "#answer" | sed 's/^[[:space:]]*//;s/[[:space:]]*$//'

# Tear down browser and server
agent-browser close >/dev/null 2>&1
pkill -f "serve.sh {fePort}" 2>/dev/null

# Guarantee exit 0
true
```

```js validation
assertEqual(Number(result.trim()), 0)
```

## Verify the SPA does not navigate on submit

Open the page, record the URL, fill the input and click submit, then record the URL again. The URL must stay at `/` — a full-page navigation or reload violates the SPA contract.

```js fixtures
({
  baseDir: ".",
  fePort: "5180",
  id: Math.random().toString(36).slice(2, 10)
})
```

```sh command
# Enter project dir
cd {baseDir}
mkdir -p .ololo/tmp

# Run command from session memory (LLM-extracted from AGENTS.md/README.md;
# arrives shell-quoted, so assign then invoke via word-splitting $R)
R={memory.run}
# Start web server in background
$R {fePort} >.ololo/tmp/esb_setup_spa.log 2>&1 &

# Wait for server boot
sleep 3

# Open page and wait for settle
agent-browser open "http://localhost:{fePort}/" >/dev/null 2>&1
agent-browser wait --load networkidle >/dev/null 2>&1

# Record URL before submit
urlBefore=$(agent-browser get url 2>/dev/null)

# Snapshot to resolve input/button refs
agent-browser snapshot -i > .ololo/tmp/esb_snap_spa.txt 2>/dev/null
inputRef=$(awk '/textbox/{sub(/.*ref=/,""); sub(/\].*/,""); print; exit}' .ololo/tmp/esb_snap_spa.txt)
submitRef=$(awk '/button/{sub(/.*ref=/,""); sub(/\].*/,""); print; exit}' .ololo/tmp/esb_snap_spa.txt)

# Type question, submit, wait for #answer
agent-browser fill "$inputRef" "{id}: what is 0 plus 0" >/dev/null 2>&1
agent-browser click "$submitRef" >/dev/null 2>&1
agent-browser wait 1500 >/dev/null 2>&1

# Record URL after submit
urlAfter=$(agent-browser get url 2>/dev/null)

# Print both URLs for comparison
echo "$urlBefore|$urlAfter"

# Tear down browser and server
agent-browser close >/dev/null 2>&1
pkill -f "serve.sh {fePort}" 2>/dev/null

# Guarantee exit 0
true
```

```js validation
const [before, after] = result.trim().split("|"); before === after
```

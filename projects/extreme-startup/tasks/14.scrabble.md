## Start the server and answer the Scrabble score question

Bring up `serve.sh {port}`, wait for it to boot, then sample a word from the fixed list (banana, september, cloud, zoo, ruby, buzzword), compute its standard English Scrabble score using an IIFE in the fixtures object, and ask "what is the english scrabble score of {word}". The response must equal the score.

```js fixtures
({
  baseDir: ".",
  port: "8088",
  qid: Math.random().toString(16).slice(2,10),
  ...(() => {
    const v = { e:1, a:1, i:1, o:1, n:1, r:1, t:1, l:1, s:1, u:1, d:2, g:2, b:3, c:3, m:3, p:3, f:4, h:4, v:4, w:4, y:4, k:5, j:8, x:8, q:10, z:10 };
    const words = ["banana", "september", "cloud", "zoo", "ruby", "buzzword"];
    const word = words[Math.floor(Math.random() * words.length)];
    const score = word.split("").reduce((s, ch) => s + (v[ch] || 0), 0);
    return { word, score };
  })()
})
```

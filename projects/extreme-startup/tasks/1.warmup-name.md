## Start the server and answer the warmup question

Bring up `serve.sh {port}`, wait for it to boot, then ask the canonical warmup question `<id>: what is your name`. Any non-empty trimmed response passes.

```js fixtures
({
  baseDir: ".",
  port: "8088",
  qid: Math.random().toString(16).slice(2,10),
})
```

```sh command
# Enter the project directory
cd {baseDir}
mkdir -p .ololo/tmp

# Run command from session memory (LLM-extracted from AGENTS.md/README.md;
# arrives shell-quoted, so assign then invoke via word-splitting $R)
R={memory.run}
# Kill any stale server on this port
pkill -f "serve.sh {port}" 2>/dev/null

# Wait for the port to free up
sleep 1

# Start the web server in the background
$R {port} >.ololo/tmp/es_warmup.log 2>&1 &

# Wait for the server to boot
sleep 3

# Ask the warmup question and trim the response
curl -s -G "http://localhost:{port}/" --data-urlencode "q={qid}: what is your name" | sed 's/^[[:space:]]*//;s/[[:space:]]*$//'
```

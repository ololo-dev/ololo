## Start the server and answer a warmup question

Every round starts with the warmup question. Bring up `serve.sh {port}` for the duration of this task — the server must stay up across the whole batch.

```js fixtures
({
  baseDir: ".",
  port: "8088",
  qid: Math.random().toString(16).slice(2,10)
})
```

```sh command
# Enter the project directory
cd {baseDir}
mkdir -p .ololo/tmp

# Run command from session memory (LLM-extracted from AGENTS.md/README.md;
# arrives shell-quoted, so assign then invoke via word-splitting $R)
R={memory.run}
# Kill any stale server on this port
pkill -f "serve.sh {port}" 2>/dev/null

# Wait for the port to free up
sleep 1

# Start the web server in the background (stays up for all sections of this task)
$R {port} >.ololo/tmp/es_final.log 2>&1 &

# Wait for the server to boot
sleep 3

# Ask the warmup question and trim the response
curl -s -G "http://localhost:{port}/" --data-urlencode "q={qid}: what is your name" | sed 's/^[[:space:]]*//;s/[[:space:]]*$//'
```

```js validation
result.trim().length > 0
```

## Answer an addition-multiplication question (precedence check)

This is the trickiest question type — the server must apply multiplication before addition, not evaluate left-to-right.

```js fixtures
({
  baseDir: ".",
  port: "8088",
  qid: Math.random().toString(16).slice(2,10),
  n1: Math.floor(Math.random() * 21),
  n2: Math.floor(Math.random() * 21)
})
```

```sh command
# Ask the addition-multiplication question and trim the response
curl -s -G "http://localhost:{port}/" --data-urlencode "q={qid}: what is {n1} plus {n2} multiplied by 3" | sed 's/^[[:space:]]*//;s/[[:space:]]*$//'
```

```js validation
assertEqual(Number(result.trim()), n1 + n2 * 3)
```

## Answer a Scrabble score question

```js fixtures
({
  baseDir: ".",
  port: "8088",
  qid: Math.random().toString(16).slice(2,10),
  ...(() => {
    const v = { e:1, a:1, i:1, o:1, n:1, r:1, t:1, l:1, s:1, u:1, d:2, g:2, b:3, c:3, m:3, p:3, f:4, h:4, v:4, w:4, y:4, k:5, j:8, x:8, q:10, z:10 };
    const words = ["banana", "september", "cloud", "zoo", "ruby", "buzzword"];
    const word = words[Math.floor(Math.random() * words.length)];
    const score = word.split("").reduce((s, ch) => s + (v[ch] || 0), 0);
    return { word, score };
  })()
})
```

```sh command
# Ask the Scrabble score question and trim the response
curl -s -G "http://localhost:{port}/" --data-urlencode "q={qid}: what is the english scrabble score of {word}" | sed 's/^[[:space:]]*//;s/[[:space:]]*$//'
```

```js validation
assertEqual(Number(result.trim()), score)
```

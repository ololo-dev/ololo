## Start the server and answer the anagram question for the "listen" set

Bring up `serve.sh {port}`, wait for it to boot, then ask "which of the following is an anagram of "listen": enlists, google, banana, silent". The correct answer is "silent".

```js fixtures
({
  baseDir: ".",
  port: "8088",
  qid: Math.random().toString(16).slice(2,10),
  anagram: "listen",
  options: "enlists, google, banana, silent",
  correct: "silent"
})
```

```sh command
# Enter the project directory
cd {baseDir}
mkdir -p .ololo/tmp

# Run command from session memory (LLM-extracted from AGENTS.md/README.md;
# arrives shell-quoted, so assign then invoke via word-splitting $R)
R={memory.run}
# Kill any stale server on this port
pkill -f "serve.sh {port}" 2>/dev/null

# Wait for the port to free up
sleep 1

# Start the web server in the background
$R {port} >.ololo/tmp/es_anag.log 2>&1 &

# Wait for the server to boot
sleep 3

# Ask the anagram question for the "listen" set and trim the response
curl -s -G "http://localhost:{port}/" --data-urlencode "q={qid}: which of the following is an anagram of \"{anagram}\": {options}" | sed 's/^[[:space:]]*//;s/[[:space:]]*$//'
```

```js validation
assertEqual(result.trim(), correct)
```

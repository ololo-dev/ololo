## Answer the Scrabble score question with derived word and score

Sample a word from the fixed list (banana, september, cloud, zoo, ruby, buzzword), compute its standard English Scrabble score using an IIFE in the fixtures object, and ask "what is the english scrabble score of {word}". #answer must equal the score.

```js fixtures
({
  baseDir: ".",
  fePort: "5180",
  id: Math.random().toString(36).slice(2, 10),
  ...((word) => ({ word, score: word.split("").reduce((s, ch) => s + ({e:1,a:1,i:1,o:1,n:1,r:1,t:1,l:1,s:1,u:1,d:2,g:2,b:3,c:3,m:3,p:3,f:4,h:4,v:4,w:4,y:4,k:5,j:8,x:8,q:10,z:10}[ch] || 0), 0) }))((["banana","september","cloud","zoo","ruby","buzzword"])[Math.floor(Math.random() * 6)])
})
```

```sh command
# Enter project dir
cd {baseDir}
mkdir -p .ololo/tmp

# Run command from session memory (LLM-extracted from AGENTS.md/README.md;
# arrives shell-quoted, so assign then invoke via word-splitting $R)
R={memory.run}
# Start web server in background
$R {fePort} >.ololo/tmp/esb_scrabble.log 2>&1 &

# Wait for server boot
sleep 3

# Open page and wait for settle
agent-browser open "http://localhost:{fePort}/" >/dev/null 2>&1
agent-browser wait --load networkidle >/dev/null 2>&1

# Snapshot to resolve input/button refs
agent-browser snapshot -i > .ololo/tmp/esb_snap_scrabble.txt 2>/dev/null
inputRef=$(awk '/textbox/{sub(/.*ref=/,""); sub(/\].*/,""); print; exit}' .ololo/tmp/esb_snap_scrabble.txt)
submitRef=$(awk '/button/{sub(/.*ref=/,""); sub(/\].*/,""); print; exit}' .ololo/tmp/esb_snap_scrabble.txt)

# Type question, submit, wait for #answer
agent-browser fill "$inputRef" "{id}: what is the english scrabble score of {word}" >/dev/null 2>&1
agent-browser click "$submitRef" >/dev/null 2>&1
agent-browser wait 1500 >/dev/null 2>&1

# Read and trim #answer
agent-browser get text "#answer" | sed 's/^[[:space:]]*//;s/[[:space:]]*$//'

# Tear down browser and server
agent-browser close >/dev/null 2>&1
pkill -f "serve.sh {fePort}" 2>/dev/null

# Guarantee exit 0
true
```

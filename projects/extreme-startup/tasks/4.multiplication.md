## Start the server and answer the multiplication question

Bring up `serve.sh {port}`, wait for it to boot, then ask "what is {n1} multiplied by {n2}" and verify the response equals n1*n2. Operands sampled from [0, 20].

```js fixtures
({
  baseDir: ".",
  port: "8088",
  qid: Math.random().toString(16).slice(2,10),
  n1: Math.floor(Math.random() * 21),
  n2: Math.floor(Math.random() * 21)
})
```

```sh command
# Enter the project directory
cd {baseDir}
mkdir -p .ololo/tmp

# Run command from session memory (LLM-extracted from AGENTS.md/README.md;
# arrives shell-quoted, so assign then invoke via word-splitting $R)
R={memory.run}
# Kill any stale server on this port
pkill -f "serve.sh {port}" 2>/dev/null

# Wait for the port to free up
sleep 1

# Start the web server in the background
$R {port} >.ololo/tmp/es_mul.log 2>&1 &

# Wait for the server to boot
sleep 3

# Ask the multiplication question and trim the response
curl -s -G "http://localhost:{port}/" --data-urlencode "q={qid}: what is {n1} multiplied by {n2}" | sed 's/^[[:space:]]*//;s/[[:space:]]*$//'
```

```js validation
assertEqual(Number(result.trim()), n1 * n2)
```

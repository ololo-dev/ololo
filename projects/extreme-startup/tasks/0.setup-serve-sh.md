## Declare how to run the project

AGENTS.md (or README.md) must document how to run the project and contain a `run:` line declaring the command that starts your server, e.g. `run: sh serve.sh`. Every later probe starts the server by invoking exactly that command with the port appended. The declared command must reference `serve.sh` (the participant contract). AGENTS.md wins when both declare one.

```yaml probe
mode: deterministic
executor: participant
capture_memory: run
```
```js fixtures
({
  baseDir: "."
})
```

```sh command
# Enter the project directory
cd {baseDir}
mkdir -p .ololo/tmp

# Extract the declared run command (AGENTS.md wins over README.md)
sed -n 's/^run: *//p' AGENTS.md README.md 2>/dev/null | head -1 | tr -d '\r'
```

```js validation
result.trim().length > 0 && result.includes("serve.sh")
```

## Verify serve.sh exists

The participant contract requires a `serve.sh` script at the project root that takes a port argument and starts an HTTP server.

```js fixtures
({
  baseDir: ".",
  port: "8088"
})
```

```sh command
# Enter the project directory
cd {baseDir}
mkdir -p .ololo/tmp

# serve.sh must exist at the project root. It is invoked through the
# declared run command (e.g. `sh serve.sh <port>`), so an executable
# bit is not required — only that the file is present.
test -f serve.sh && echo "ok" || echo "missing"
```

```js validation
assertEqual(result.trim(), "ok")
```

## Verify serve.sh starts an HTTP server that responds on the given port

Run `serve.sh {port}` in the background, wait for startup, then curl the root endpoint. Any HTTP response (even 404) proves the server is listening.

```js fixtures
({
  baseDir: ".",
  port: "8088"
})
```

```sh command
# Enter the project directory
cd {baseDir}
mkdir -p .ololo/tmp

# Run command from session memory (LLM-extracted from AGENTS.md/README.md;
# arrives shell-quoted, so assign then invoke via word-splitting $R)
R={memory.run}
# Start the web server in the background
$R {port} >.ololo/tmp/es_setup.log 2>&1 &

# Wait for the server to boot
sleep 3

# Probe the root endpoint; any HTTP response proves it is listening
curl -s -o /dev/null -w "%{http_code}" "http://localhost:{port}/"

# Stop the server (this section only needed a liveness probe)
pkill -f "serve.sh {port}" 2>/dev/null

# Guarantee a 0 exit code regardless of pkill matches
true
```

```js validation
const code = Number(result.trim()); code >= 200 && code < 500
```

## Answer the multiplication-addition question respecting operator precedence

Ask "what is {n1} multiplied by {n2} plus {n3}" and verify #answer equals n1*n2 + n3. Standard operator precedence applies (multiplication before addition). Operands sampled from [0,20].

```js fixtures
({
  baseDir: ".",
  fePort: "5180",
  id: Math.random().toString(36).slice(2, 10),
  n1: Math.floor(Math.random() * 21),
  n2: Math.floor(Math.random() * 21),
  n3: Math.floor(Math.random() * 21)
})
```

```sh command
# Enter project dir
cd {baseDir}
mkdir -p .ololo/tmp

# Run command from session memory (LLM-extracted from AGENTS.md/README.md;
# arrives shell-quoted, so assign then invoke via word-splitting $R)
R={memory.run}
# Start web server in background
$R {fePort} >.ololo/tmp/esb_ma.log 2>&1 &

# Wait for server boot
sleep 3

# Open page and wait for settle
agent-browser open "http://localhost:{fePort}/" >/dev/null 2>&1
agent-browser wait --load networkidle >/dev/null 2>&1

# Snapshot to resolve input/button refs
agent-browser snapshot -i > .ololo/tmp/esb_snap_ma.txt 2>/dev/null
inputRef=$(awk '/textbox/{sub(/.*ref=/,""); sub(/\].*/,""); print; exit}' .ololo/tmp/esb_snap_ma.txt)
submitRef=$(awk '/button/{sub(/.*ref=/,""); sub(/\].*/,""); print; exit}' .ololo/tmp/esb_snap_ma.txt)

# Type question, submit, wait for #answer
agent-browser fill "$inputRef" "{id}: what is {n1} multiplied by {n2} plus {n3}" >/dev/null 2>&1
agent-browser click "$submitRef" >/dev/null 2>&1
agent-browser wait 1500 >/dev/null 2>&1

# Read and trim #answer
agent-browser get text "#answer" | sed 's/^[[:space:]]*//;s/[[:space:]]*$//'

# Tear down browser and server
agent-browser close >/dev/null 2>&1
pkill -f "serve.sh {fePort}" 2>/dev/null

# Guarantee exit 0
true
```

assertEqual(Number(result.trim()), n1 * n2 + n3)

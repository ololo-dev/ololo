## Start the server and answer the primes question

Bring up `serve.sh {port}`, wait for it to boot, then build a candidate list mixing small primes with obvious composites. Ask "which of the following numbers are primes: ...". The response must list exactly the primes, in any order. Compared as sorted sets.

```js fixtures
({
  baseDir: ".",
  port: "8088",
  qid: Math.random().toString(16).slice(2,10),
  list: [2, 3, 5, 7, 11, 13, 17, 4, 6, 8, 9, 10, 15, 21, 25].sort(() => Math.random() - 0.5).join(", ")
})
```

# Enter the project directory

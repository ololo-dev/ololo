## Start the server and answer the Eiffel tower city question

Bring up `serve.sh {port}`, wait for it to boot, then ask "which city is the Eiffel tower in"; the answer is "Paris".

```js fixtures
({
  baseDir: ".",
  port: "8088",
  qid: Math.random().toString(16).slice(2,10),
  question: "which city is the Eiffel tower in",
  answer: "Paris",
  __secret: ["answer"],
  __secret_expected: true
})
```

```sh command
# Enter the project directory
cd {baseDir}
mkdir -p .ololo/tmp

# Run command from session memory (LLM-extracted from AGENTS.md/README.md;
# arrives shell-quoted, so assign then invoke via word-splitting $R)
R={memory.run}
# Kill any stale server on this port
pkill -f "serve.sh {port}" 2>/dev/null

# Wait for the port to free up
sleep 1

# Start the web server in the background
$R {port} >.ololo/tmp/es_gk.log 2>&1 &

# Wait for the server to boot
sleep 3

# Ask the Eiffel tower city question and trim the response
curl -s -G "http://localhost:{port}/" --data-urlencode "q={qid}: {question}" | sed 's/^[[:space:]]*//;s/[[:space:]]*$//'
```

```js validation
result.trim().toLowerCase() === answer.toLowerCase()
```

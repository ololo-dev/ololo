## Declare how to run the project

AGENTS.md (or README.md) must document how to run the project and contain a `run:` line declaring the command that answers a question, e.g. `run: sh answer.sh`. Every later probe invokes exactly that command with `-q "<question>"` appended. The declared command must reference `answer.sh` (the participant contract). AGENTS.md wins when both declare one.

```yaml probe
mode: deterministic
executor: participant
capture_memory: run
```
```js fixtures
({
  baseDir: "."
})
```

```sh command
# Enter the project directory
cd {baseDir}
mkdir -p .ololo/tmp

# Extract the declared run command (AGENTS.md wins over README.md)
sed -n 's/^run: *//p' AGENTS.md README.md 2>/dev/null | head -1 | tr -d '\r'
```

```js validation
result.trim().length > 0 && result.includes("answer.sh")
```

## Verify answer.sh answers a one-shot question

Invoke `sh {command} -q "..."` with a trivial arithmetic question and assert it prints the right answer to stdout with exit code 0.

```js fixtures
({
  baseDir: ".",
  id: Math.random().toString(36).slice(2, 10),
  command: "answer.sh"
})
```

```sh command
# Enter the project directory
cd {baseDir}
mkdir -p .ololo/tmp

# Run command from session memory (LLM-extracted from AGENTS.md/README.md;
# arrives shell-quoted, so assign then invoke via word-splitting $R)
R={memory.run}

# Invoke the participant script with a trivial arithmetic question and trim whitespace
$R -q "{id}: what is 0 plus 0" | sed 's/^[[:space:]]*//;s/[[:space:]]*$//'
```

```js validation
assertEqual(Number(result.trim()), 0)
```

## Declare how to test the project

AGENTS.md (or README.md) must also contain a `test:` line declaring the command that runs your test suite, e.g. `test: sh test.sh` or `test: npm test`. Write at least a smoke test and keep it green — the declared command is captured into session memory and later probes and judges may run exactly what it says. AGENTS.md wins when both declare one.

```yaml probe
mode: deterministic
executor: participant
capture_memory: test
```

```js fixtures
({
  baseDir: "."
})
```

```sh command
# Enter the project directory
cd {baseDir}

# Extract the declared test command (AGENTS.md wins over README.md)
sed -n 's/^test: *//p' AGENTS.md README.md 2>/dev/null | head -1 | tr -d '\r'
```

```js validation
result.trim().length > 0
```

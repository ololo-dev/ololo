## Answer the maximum question with the largest number in the list

Build a comma-separated list: a few random values from [0,1000] plus candidates from [1,100], then ask "which of the following numbers is the largest: ...". The response must equal the list's maximum.

```js fixtures
({
  baseDir: ".",
  id: Math.random().toString(36).slice(2, 10),
  command: "answer.sh",
  list: Array.from({length: 5}, () => Math.floor(Math.random() * 1001)).join(", ")
})
```

```sh command
# Enter the project directory
cd {baseDir}
mkdir -p .ololo/tmp

# Run command from session memory (LLM-extracted from AGENTS.md/README.md;
# arrives shell-quoted, so assign then invoke via word-splitting $R)
R={memory.run}

# Ask the maximum question and trim whitespace
$R -q "{id}: which of the following numbers is the largest: {list}" | sed 's/^[[:space:]]*//;s/[[:space:]]*$//'
```

```js validation
assertEqual(Number(result.trim()), Math.max(...list.split(",").map(s => Number(s.trim()))))
```

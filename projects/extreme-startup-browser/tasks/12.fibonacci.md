## Answer the Fibonacci question with the correct term

Sample n in [4,23], build the ordinal (1st/2nd/3rd/Nth) and ask "what is the {ordinal} number in the Fibonacci sequence". Verify #answer equals F(n) where F(0)=0, F(1)=1, F(2)=1, F(3)=2...

```js fixtures
({
  baseDir: ".",
  fePort: "5180",
  id: Math.random().toString(36).slice(2, 10),
  ...((n) => ({ n, ordinal: n + (["th","st","nd","rd"][(n%100-20)%10] || ["th","st","nd","rd"][n%100] || "th") }))(Math.floor(Math.random() * 20) + 4)
})
```

```sh command
# Enter project dir
cd {baseDir}
mkdir -p .ololo/tmp

# Run command from session memory (LLM-extracted from AGENTS.md/README.md;

R={memory.run}
# Start web server in background
$R {fePort} >.ololo/tmp/esb_fib.log 2>&1 &

# Wait for server boot
sleep 3

# Open page and wait for settle
agent-browser open "http://localhost:{fePort}/" >/dev/null 2>&1

# Snapshot to resolve input/button refs
agent-browser snapshot -i > .ololo/tmp/esb_snap_fib.txt 2>/dev/null
inputRef=$(awk '/textbox/{sub(/.*ref=/,""); sub(/\].*/,""); print; exit}' .ololo/tmp/esb_snap_fib.txt)
submitRef=$(awk '/button/{sub(/.*ref=/,""); sub(/\].*/,""); print; exit}' .ololo/tmp/esb_snap_fib.txt)

# Type question, submit, wait for #answer
agent-browser fill "$inputRef" "{id}: what is the {ordinal} number in the Fibonacci sequence" >/dev/null 2>&1
agent-browser click "$submitRef" >/dev/null 2>&1
agent-browser wait 1500 >/dev/null 2>&1

# Read and trim #answer
agent-browser get text "#answer" | sed 's/^[[:space:]]*//;s/[[:space:]]*$//'

# Tear down browser and server
agent-browser close >/dev/null 2>&1
pkill -f "serve.sh {fePort}" 2>/dev/null

# Guarantee exit 0
true
```

## Verify the language declaration exists

AGENTS.md (or README.md) must contain a `run:` line declaring the command that runs your solution, e.g. `run: node answer.js`. AGENTS.md wins when both declare one.

```yaml probe
mode: deterministic
executor: participant
capture_memory: run
```

```js fixtures
  baseDir: "."
})
```

```sh command

# Extract the declared run command (AGENTS.md wins over README.md)
sed -n 's/^run: *//p' AGENTS.md README.md 2>/dev/null | head -1 | tr -d '\r'
```


## Answer an array input element-wise

The list holds six numbers from [1, 999] — at least one from each category (plain, divisible by 3, contains 3, both), shuffled. The response must be the comma-separated results in the same order; whitespace around commas is tolerated.

```js fixtures
({
  baseDir: ".",
  list: (() => {
    const pick = ok => { let n; do { n = Math.floor(Math.random() * 999) + 1; } while (!ok(n)); return n; };
    const div = n => n % 3 === 0, has = n => String(n).includes("3");
    const pool = [
      pick(n => !div(n) && !has(n)),
      pick(n => div(n) && !has(n)),
      pick(n => !div(n) && has(n)),
      pick(n => div(n) && has(n)),
      pick(() => true),
      pick(() => true)
    ];
    for (let i = pool.length - 1; i > 0; i--) {
      const j = Math.floor(Math.random() * (i + 1));
      [pool[i], pool[j]] = [pool[j], pool[i]];
    }
    return pool.join(",");
  })()
})
```

```sh command
# Enter the project directory
cd {baseDir}
mkdir -p .ololo/tmp

# Run command from session memory (LLM-extracted from AGENTS.md/README.md;
# arrives shell-quoted, so assign then invoke via word-splitting $R)
R={memory.run}

# Pass the comma-separated list as the single argument and trim the response
$R "{list}" | sed 's/^[[:space:]]*//;s/[[:space:]]*$//'
```

```js validation
const hop = s => { const n = Number(s); const d = n % 3 === 0, c = s.includes("3"); return d && c ? "hop-hop" : d || c ? "hop" : s; };
assertEqual(result.replace(/\s+/g, ""), list.split(",").map(hop).join(","))
```

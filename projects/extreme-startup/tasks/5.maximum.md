## Start the server and answer the maximum question

Bring up `serve.sh {port}`, wait for it to boot, then build a comma-separated list (a few random values from [0,1000] plus candidates from [1,100]) and ask "which of the following numbers is the largest: ...". The response must equal the list's maximum.

```js fixtures
({
  baseDir: ".",
  port: "8088",
  qid: Math.random().toString(16).slice(2,10),
  list: Array.from({length: 5}, () => Math.floor(Math.random() * 1001)).join(", ")
})
```

```sh command
# Enter the project directory
cd {baseDir}
mkdir -p .ololo/tmp

# Run command from session memory (LLM-extracted from AGENTS.md/README.md;
# arrives shell-quoted, so assign then invoke via word-splitting $R)
R={memory.run}
# Kill any stale server on this port
pkill -f "serve.sh {port}" 2>/dev/null

# Wait for the port to free up
sleep 1

# Start the web server in the background
$R {port} >.ololo/tmp/es_max.log 2>&1 &

# Wait for the server to boot
sleep 3

# Ask the maximum question and trim the response
curl -s -G "http://localhost:{port}/" --data-urlencode "q={qid}: which of the following numbers is the largest: {list}" | sed 's/^[[:space:]]*//;s/[[:space:]]*$//'
```

```js validation
const nums = list.split(",").map(s => Number(s.trim())); assertEqual(Number(result.trim()), Math.max(...nums))
```

## Answer a random hop question correctly

Any category can come up - plain, divisible by 3, containing 3, or both. The probe runs the command declared by your `run:` line with the number as its single argument.

```js fixtures
({
  baseDir: ".",
  n: Math.floor(Math.random() * 999) + 1
})
```

```sh command
# Enter the project directory
cd {baseDir}
mkdir -p .ololo/tmp

# Run command from session memory (LLM-extracted from AGENTS.md/README.md;
# arrives shell-quoted, so assign then invoke via word-splitting $R)
R={memory.run}

# Pass the number as the single argument and trim the response
$R "{n}" | sed 's/^[[:space:]]*//;s/[[:space:]]*$//'
```

```js validation
const hop = s => { const v = Number(s); const d = v % 3 === 0, c = s.includes("3"); return d && c ? "hop-hop" : d || c ? "hop" : s; };
assertEqual(result.trim(), hop(String(n)))
```

## Answer a random array question correctly

The list holds six numbers from [1, 999] - at least one from each category, shuffled. Whitespace around commas is tolerated.

```js fixtures
({
  baseDir: ".",
  list: (() => {
    const pick = ok => { let n; do { n = Math.floor(Math.random() * 999) + 1; } while (!ok(n)); return n; };
    const div = n => n % 3 === 0, has = n => String(n).includes("3");
    const pool = [
      pick(n => !div(n) && !has(n)),
      pick(n => div(n) && !has(n)),
      pick(n => !div(n) && has(n)),
      pick(n => div(n) && has(n)),
      pick(() => true),
      pick(() => true)
    ];
    for (let i = pool.length - 1; i > 0; i--) {
      const j = Math.floor(Math.random() * (i + 1));
      [pool[i], pool[j]] = [pool[j], pool[i]];
    }
    return pool.join(",");
  })()
})
```

```sh command
# Enter the project directory
cd {baseDir}
mkdir -p .ololo/tmp

# Run command from session memory (LLM-extracted from AGENTS.md/README.md;
# arrives shell-quoted, so assign then invoke via word-splitting $R)
R={memory.run}

# Pass the comma-separated list as the single argument and trim the response
$R "{list}" | sed 's/^[[:space:]]*//;s/[[:space:]]*$//'
```

```js validation
const hop = s => { const v = Number(s); const d = v % 3 === 0, c = s.includes("3"); return d && c ? "hop-hop" : d || c ? "hop" : s; };
assertEqual(result.replace(/\s+/g, ""), list.split(",").map(hop).join(","))
```

## Verify the solution fits in 160 bytes

Every project file except .git/, .ololo/, AGENTS.md, README.md and .gitignore, plus the declared `run:` command itself. Documentation is free only while it stays documentation: a run line that names AGENTS.md or README.md makes that file part of the solution, and it counts.

```js fixtures
({
  baseDir: "."
})
```

```sh command
# Enter the project directory
cd {baseDir}
mkdir -p .ololo/tmp

# The solution is every project file plus the run command that invokes it.
R={memory.run}

# Helper files and a leftover answer.sh count too
F=$(find . -type f ! -path "*/.git/*" ! -path "*/.ololo/*" ! -name AGENTS.md ! -name README.md ! -name ".gitignore" ! -name ".DS_Store" -exec cat {} + | wc -c)

# Documentation is free only while it stays documentation: a run line that
# names AGENTS.md or README.md makes that file code, so it counts.
D=0
case "$R" in *AGENTS.md*) [ -f AGENTS.md ] && D=$(( D + $(wc -c < AGENTS.md) ));; esac
case "$R" in *README.md*) [ -f README.md ] && D=$(( D + $(wc -c < README.md) ));; esac

echo $(( F + D + $(printf %s "$R" | wc -c) ))
```

```js validation
Number(result.trim()) <= 160
```

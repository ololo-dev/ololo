## Answer the square-and-cube question with the matching numbers

Build a candidate list mixing perfect sixth powers (k**6 for k in 1..4) with plain squares (k**2). Ask "which of the following numbers is both a square and a cube: ...". The response must list exactly the numbers that are both perfect squares and perfect cubes (i.e. x where round(sqrt(x))**2 == x and round(cbrt(x))**3 == x). Accept the answer in any order; compare as sorted sets.

```js validation
const isSquare = x => { const r = Math.round(Math.sqrt(x)); return r*r === x; };
const isCube = x => { const r = Math.round(Math.cbrt(x)); return r*r*r === x; };
const nums = list.split(",").map(s => Number(s.trim()));
const expected = nums.filter(x => isSquare(x) && isCube(x)).sort((a,b)=>a-b).join(", ");
```
